## [0.1.0] - 2026-10-13

### Added

- Waste collection dates from the 978 sources of Waste Collection Schedule 2.35.0 (towns, waste operators, apps and ICS calendar links), up to three schedules.
- One device per schedule: days until the next collection, the waste types of that collection, and days until the next collection of each waste type.
- Calendar variant (the Waste Collection Calendar integration, same image): one calendar per schedule for each user who enables it, an all-day event per collection.
- Dashboard widget "Upcoming collections": the next collection days with a bin of the right color, the state of each schedule and a Refresh button.
- Scene triggers: collection tomorrow (reminder time the evening before), waste type collected tomorrow, collection today (morning time), update failed.
- Scene actions: get the next collection (optionally of one waste type), update the collection dates.
- Configuration buttons: find a source by town, operator or country, and test the configured schedules.
- Rename and hide waste types, update every 6, 12 or 24 hours, texts in English, French, German and Spanish.
